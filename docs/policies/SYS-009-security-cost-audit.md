# SYS-009 보안·비용·감사 정책

상태: `IMPLEMENTED / POLICY BASELINE`

- 보안: 기본 거부, 최소 권한, 운영 직접 접근 금지, 비밀값 대신 브로커 참조를 사용한다.
- 비용: 공급자 호출 전 예산을 예약하고 80% 경고, 100% 자동 중지하며 자동 증액하지 않는다.
- 감사: 작업·승인·지식·공급자·비용·보안·산출물·게이트 이벤트를 UTC 기준 불변 해시 체인으로 남긴다.
- 위험: 규칙·RNG·지급·원장·보안·권리·예산·출시는 항상 고위험이며 자동 하향하지 않는다.

정책상 예산·법무·외부 공개·운영 출시·R0 기준선의 최종 승인은 사람에게만 있다.
