# SYS-005 지식 승인·검색·폐기

상태: `IMPLEMENTED / AUTOMATED_CHECKS_REQUIRED`

대화, 외부 자료, 외부 AI 출력은 자동 학습 데이터가 아니다. 모든 후보는 출처·권리·보안·품질
검토를 거쳐 `APPROVED` 상태가 된 버전만 검색할 수 있다. 승인자와 제안자는 분리하며,
승인된 버전은 변경하지 않고 새 버전으로 대체한다. 폐기된 항목은 신규 검색에서 제외하되
감사와 재현을 위해 보존한다.

`studio_core/knowledge.py`는 상태, 범위, 에이전트 허용 목록, 정보등급, AI 사용권을 모두
통과한 경우에만 검색을 허용한다.
