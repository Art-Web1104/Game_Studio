# ADR-0003: 프로그래밍 작업은 Claude Code로 단일화

- 상태: Accepted for R1 candidate
- 날짜: 2026-08-31
- 결정자: USER
- 결정 근거 문구: `코덱스 안써도 돼 그냥 클로드에 모두 맡겨`

## 결정

1. 프로그래밍 작업의 생성 공급자는 Claude Code 하나로 단일화한다.
2. Codex는 코드 생성·수정·리뷰의 대체 경로로 사용하지 않는다.
3. Claude Code가 클라이언트, 게임 서버, 백엔드, 프로토콜, 테스트, 빌드·DevOps를 담당한다.
4. Claude 내부에는 클라이언트, 게임 서버, 백엔드·플랫폼, 읽기 전용 코드 리뷰 에이전트를 둔다.
5. Claude가 생성과 내부 리뷰를 담당해도 최종 QA·예산·법무·배포·출시는 독립 승인으로 남긴다.

## 적용 경계

- R0 `1.1.0` 승인본은 변경하지 않는다.
- 본 결정은 R1 후보부터 적용한다.
- Claude 연결이 완료되지 않은 동안 프로그래밍 작업은 다른 모델로 우회하지 않고 `BLOCKED` 처리한다.
- 현금 환전·실물 보상·운영 직접 접근·R5 이전 일정 수립 금지는 그대로 유지한다.
