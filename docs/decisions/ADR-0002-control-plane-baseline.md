# ADR-0002: SYS-004~SYS-009 제어 시스템 기준선

- 상태: Accepted / R0 approved
- 날짜: 2026-08-28
- 기준선: 1.1.0

## 결정

1. 부서별 채팅 허브와 하위방을 정책 파일로 정의하고 접근은 기본 거부한다.
2. 작업 상태, 지식 수명주기, 외부 AI 호출을 기계 판독 계약으로 통제한다.
3. 외부 AI는 공급자 중립 어댑터 뒤에 두며 미설정 공급자는 호출하지 않는다.
4. 상시 에이전트는 역할별 Eval Set과 독립 검토를 통과해야 활성화할 수 있다.
5. 첫 수직 검증은 유럽식 단일 제로 룰렛의 결정론적 규칙·지급·원장 QA로 한다.
6. 예산·법무·외부 공개·운영 출시·R0 최종 승인은 사람에게 남긴다.

## 결과

시스템 골조는 문서뿐 아니라 참조 판정 코드와 부정 테스트를 갖는다. 외부 서비스의 실제
계정 연결과 게임 제작 일정은 이 결정 범위에 포함하지 않는다.
