# R1 룰렛 규칙·경제 기준선

상태: `CANDIDATE / AUTOMATED VALIDATION IN PROGRESS`

R1은 유럽식 단일 제로 룰렛을 첫 수직 검증 대상으로 삼아 다음 계약을 고정한다.

- 0~36 포켓, 지원 베팅과 테이블 기하 유효성
- 각 베팅의 지급 배수, 공통 RTP `36/37`, 하우스 엣지 `1/37`
- 정수 가상 칩, 합계 0의 균형 원장, 멱등 거래
- 서버 권위 라운드 상태와 중복 정산 금지
- RNG 어댑터 입력·출력·감사·실패 처리
- 현금 환전·실물 보상·운영 수익화·제작 일정 제외

생산용 난수 구현, 데이터베이스 동시성, 부하·보안 실행은 R2에서 다룬다. 생산 경제 수치와
수익화는 시뮬레이션과 시장별 법무 검토 전까지 확정하지 않는다.
