# SYS-008 룰렛 테스트 명세

상태: `IMPLEMENTED / RULES BASELINE ONLY`

첫 수직 검증 대상은 유럽식 단일 제로 룰렛이다. 규칙 원본은 0~36 포켓, 지원 베팅 유형,
순이익 배수, 0 처리, 정수 칩, 서버 권위, 결정론적 리플레이 계약을 정의한다.

QA 게이트는 규칙과 지급 전수 검증, 고정 벡터, 원장 속성, 중복 요청, 장애·재접속,
통계 이상 감시를 포함한다. 통계 시험은 정확한 규칙·지급 시험을 대체할 수 없다.
이 명세의 통과는 룰렛 규칙 기준선 통과이며 상용 출시 승인이 아니다.
